# 🏪 Ryenz Store

Ryenz Store adalah platform e-commerce digital products yang menyediakan:
- 👑 Alight Motion Premium
- 🎬 CapCut Premium
- 📸 Jasa Foto HD
- ✨ Wink Premium
- 🌟 Meitu Premium
- 📚 VT Tutor HD

## Tech Stack
- **Backend**: Node.js + Express.js
- **Frontend**: React + Vite
- **Database**: PostgreSQL
- **QR Code**: qrcode.js
- **Payment**: Midtrans/Manual
- **Authentication**: JWT

## Instalasi

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
